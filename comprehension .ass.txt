1️⃣ Filter Dictionary - Keep Items with Value Greater than 10
Given dictionary:
d = {'a': 5, 'b': 15, 'c': 25, 'd': 7}
Create a new dictionary only with items where value > 10

solution : d = {'a': 5, 'b': 15, 'c': 25, 'd': 7}
result = {key: value for key, value in d.items() if value > 10}
print(result)

Expected Output:
{'b': 15, 'c': 25}

 3️⃣ASCII Mapping for Lowercase Letters
Map each lowercase letter 'a' to 'z' to its ASCII value

result = {chr(i): i for i in range(97, 123)}
print(result)

Expected Output:

4️⃣ Create Reverse Word Dictionary
Given list of words:
words = ["cat", "dog", "bat"]
Create a dictionary with words as keys and their reversed strings as values.

words = ["cat", "dog", "bat"]
result = {word: word[::-1] for word in words}
print(result)

Expected Output:
{'cat': 'tac', 'dog': 'god', 'bat': 'tab'}

5️⃣ Uppercase Keys
Given list:
letters = ['a', 'b', 'c']
Create a dictionary with uppercase letters as keys and their ASCII values as values. 

letters = ['a', 'b', 'c']
result = {letter.upper(): ord(letter.upper()) for letter in letters}
print(result)

Expected Output:
{'A': 65, 'B': 66, 'C': 67}
