3Q. Find the most frequent element.

a = [1, 2, 2, 3, 3, 3, 4]

    if a.count(i) > a.count(most):
        most = i
print("Most frequent =", most)

output:Most frequent = 3

13Q. Check whether a list is sorted.

a = [5, 2, 8, 1, 3]

for i in range(len(a)):
    for j in range(i + 1, len(a)):
        if a[i] > a[j]:
            a[i], a[j] = a[j], a[i]
print(a)

output:[1, 2, 3, 5, 8]
